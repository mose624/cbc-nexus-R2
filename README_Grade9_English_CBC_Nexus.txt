CBC Nexus — Grade 9 English Assessment

Included in this build:
- 30 multiple-choice questions, 1 mark each (30 marks total).
- Reading comprehension, paragraph analysis, grammar, poetry, and cross-text analysis.
- Supplied answer key with feedback/explanations.
- Grade 9 English added to the quick-access assessment panel.
- Existing learner information, progress, one-attempt workflow and two-minute-per-question timer preserved.

Timing: the source suggests 45 minutes; the site-wide timing rule is 2 minutes per question, so the site allocates 60 minutes.

Question 12 was clarified to specify plural ownership (several girls) because the original apostrophe question had two grammatically possible options depending on singular/plural meaning. The intended answer remains C.

This is original practice content, not an official KICD/KNEC exam. The offline HTML build stores records in the current browser. Online reporting, cross-device attempt locking and AI marking require the Supabase backend to be configured and deployed.
