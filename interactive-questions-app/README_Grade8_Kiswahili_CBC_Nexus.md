# Grade 8 Kiswahili added to CBC Nexus

This package adds a Grade 8 Kiswahili practice paper with 30 multiple-choice questions. Topics include ufahamu, sarufi, mpangilio wa mawazo, matumizi ya lugha, ushairi, uandishi and critical thinking. Suggested answers and explanations are included in each question.

The supplied paper states 45 minutes, while the current CBC Nexus site-wide policy allocates 2 minutes per question (60 minutes for 30 questions). The assessment description discloses this difference rather than silently changing the stated source time.

The answer key is derived from the supplied questions because no answer letters were included. It is a suggested key and should be reviewed by a teacher before formal assessment use. This is practice content, not an official KNEC examination.

The website has not been published automatically. Online result storage, cross-device single-attempt enforcement and AI written marking require the Supabase configuration described in the other README files.
