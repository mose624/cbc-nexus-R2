# Grade 7 Agriculture — CBC Nexus update

This update adds a 30-question Grade 7 Agriculture higher-order practice bank under the Grade 7 catalogue label **Agriculture & Nutrition**. It includes all multiple-choice options, a suggested correct answer and a brief explanation for each question.

Coverage includes soil health and conservation, crop production, livestock health and welfare, farm tools and safety, sustainable agriculture, and farm economics/problem-solving.

The source paper states 45 minutes. The existing CBC Nexus runtime applies two minutes per question, so the online assessment timer is 60 minutes unless the site-wide timing policy is changed separately. The questions are original practice material, not an official KNEC examination.

The suggested answer key was derived from the supplied questions because the source did not provide a separate key. Review it before formal assessment.
