# Grade 7 Christian Religious Education (CRE) – CBC Nexus integration

- Added 30 multiple-choice HOTS questions to the Grade 7 CRE assessment bank.
- Covered creation and stewardship, Bible narratives, Jesus' teachings, Christian values, prayer, worship, church service and social responsibility.
- Included a suggested answer key and explanatory feedback. The key was derived from the supplied questions because no separate letter key was provided.
- Existing CBC Nexus timing remains 2 minutes per question (60 minutes), while the source paper specifies 45 minutes.
- This is practice content, not an official KNEC examination.
