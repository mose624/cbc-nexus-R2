# Grade 7 Pre-Technical Studies added to CBC Nexus

Added a 30-item multiple-choice HOTS practice assessment to `index.html` using the Grade 7 specialized-bank structure. Topics cover workshop safety, tools and materials; technical drawing and design; structures and mechanisms; electricity and electronics; digital technology; production, entrepreneurship and sustainability.

Each question has four options, a suggested correct option, and feedback/explanation. The key is derived from the submitted questions because no separate answer letters were supplied.

The assessment appears in the Grade 7 quick-access hub and uses the existing two-minute-per-question timer (60 minutes for 30 questions), although the source paper says 45 minutes. This is original practice material, not an official KNEC examination.

Online reporting and cross-device attempt enforcement remain dependent on deployment and Supabase configuration.
