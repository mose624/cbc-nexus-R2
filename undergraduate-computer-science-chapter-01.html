1. What computer science studies

Computer science is the systematic study of computation: what problems can be solved, how solutions can be represented as algorithms, how those algorithms can be implemented, and how computational systems behave. It includes theory, software, hardware, data, networks, human-computer interaction and the social consequences of technology. It is not limited to learning how to use applications or writing code. A computer scientist asks whether a problem is computable, whether a solution is correct, how much time and memory it needs, and how people can use it safely.

2. Computational thinking

Computational thinking is a disciplined way of formulating problems so that a human or machine can solve them. Decomposition divides a complex task into manageable parts. Pattern recognition identifies similarities across cases. Abstraction focuses on essential details while temporarily ignoring irrelevant complexity. Algorithm design specifies an ordered solution. Evaluation checks correctness, efficiency, usability and limitations. These practices apply to software development, scientific modelling, logistics, health information systems and everyday decision-making.

3. Data, information and knowledge

Data are recorded observations or symbols; information is data organised and interpreted in context; knowledge is an understanding that supports explanation or action. A temperature reading becomes more useful when associated with a unit, time, location and measurement method. Poor quality data can produce misleading information even when calculations are correct. Data quality dimensions include accuracy, completeness, consistency, timeliness, validity and uniqueness. Systems should preserve provenance and document transformations.

4. Hardware and software

Hardware is the physical equipment of a computing system: processor, memory, storage, input devices, output devices and communication interfaces. Software is the set of instructions and related data that direct hardware. System software manages resources and provides platforms; application software supports user tasks; development software helps create and test programs. Firmware provides low-level control for devices. Hardware and software depend on each other: an application relies on operating-system services and physical resources.

5. The stored-program computer and CPU

Most general-purpose computers use a stored-program architecture in which instructions and data are represented in memory. The central processing unit fetches instructions, decodes their meaning and executes operations. The control unit coordinates activity; the arithmetic logic unit performs arithmetic and logical operations; registers provide very fast temporary storage. The program counter identifies the next instruction, while other registers hold operands, addresses and intermediate results. Performance depends on many factors, not clock speed alone.

6. Memory and storage hierarchy

Registers and cache are very fast but small. Main memory (RAM) holds programs and data currently in use and is generally volatile. Secondary storage such as solid-state drives and hard disks retains data when power is removed. The hierarchy balances speed, capacity and cost. Locality of reference explains why caches are effective: programs often reuse recently accessed data or access nearby addresses. Virtual memory gives processes an abstraction of a large address space, backed by physical memory and storage.

7. Input, output and peripheral devices

Input devices convert physical actions or signals into data, for example keyboards, touchscreens, cameras, microphones and sensors. Output devices present results through displays, printers, speakers or actuators. A device controller and driver help the operating system communicate with hardware. Accessibility, reliability, latency, resolution, sampling and environmental conditions affect device choice. In embedded systems, sensors and actuators connect computation to the physical world.

8. Operating systems and system software

An operating system manages processes, memory, files, devices, users and security. It provides abstractions that allow applications to use hardware without controlling every electrical detail. A kernel is the privileged core; system calls provide controlled access to services. Other system software includes device drivers, utilities, language runtimes and firmware. Different systems optimise for desktop interaction, servers, mobile devices, real-time control or embedded constraints.

9. Number systems and digital representation

Digital systems represent information using discrete states, commonly binary digits 0 and 1. Binary place values are powers of two; hexadecimal is a compact representation of binary groups. Text is encoded using character standards such as Unicode. Images are represented as pixels with colour values; audio is sampled and quantised; video combines timed image frames and sound. Representation choices affect precision, storage, compatibility and possible information loss.

10. Computer networks and the internet

A network connects devices so they can exchange data and share services. Local area networks connect nearby devices; wide area networks span larger regions. The internet is a network of interconnected networks that use common protocols. Packet switching divides data into packets that can travel through different paths. IP provides addressing and routing, while transport protocols such as TCP and UDP support communication with different reliability and latency properties. DNS maps domain names to network addresses.

11. Computing ethics, privacy and professional practice

Computing systems influence privacy, employment, safety, access to services and public trust. Ethical practice considers consent, fairness, transparency, accessibility, security, environmental impact and accountability. Professionals should protect credentials and data, respect intellectual property, test systems responsibly, disclose limitations and avoid unauthorised access. Legal requirements vary by jurisdiction and sector. A technically functional system is not automatically ethical, inclusive or safe.

Practical laboratory activity

  1. Write a short problem specification, listing inputs, outputs and constraints.
  2. Draw a diagram or write pseudocode before implementation.
  3. Implement a small example in an appropriate language or tool.
  4. Test normal, boundary and invalid cases; record actual and expected results.
  5. Explain the design trade-offs and suggest one improvement.

Use authorised software and test environments. Do not run experiments on systems or data without permission.

Worked reasoning and self-check

For every problem, state the assumptions first. Work through a small input manually, record each important state transition and compare the final result with the specification. If the result differs, isolate the smallest failing example and revise the reasoning before changing code. For performance questions, identify the input-size variable and count the dominant operation rather than guessing from execution time alone.

Examination and revision questions

Answer with definitions, explanations, diagrams, calculations or code traces as appropriate. Show working for numerical and algorithmic questions.

  1. Define computer science.

    Show answer guidance

    The systematic study of computation, algorithms, information and computational systems, including their design, implementation, analysis and impact.

  2. Differentiate data and information.

    Show answer guidance

    Data are recorded observations; information is data interpreted and organised in context.

  3. Name four elements of computational thinking.

    Show answer guidance

    Decomposition, pattern recognition, abstraction and algorithm design.

  4. What does the CPU do?

    Show answer guidance

    It fetches, decodes and executes instructions, coordinating computational operations.

  5. Differentiate RAM from persistent storage.

    Show answer guidance

    RAM is working memory and is generally volatile; persistent storage retains data without power.

  6. What is an operating system?

    Show answer guidance

    System software that manages hardware resources and provides services and abstractions to applications.

  7. Why is binary used in digital systems?

    Show answer guidance

    Two-state representations can be implemented reliably using electronic states with distinguishable voltage ranges.

  8. What is a network protocol?

    Show answer guidance

    A defined set of rules governing communication between devices or software components.

  9. State three dimensions of data quality.

    Show answer guidance

    Accuracy, completeness, consistency, timeliness, validity or uniqueness.

  10. What is abstraction?

    Show answer guidance

    Focusing on essential features while hiding details not currently needed.

  11. Differentiate hardware and software.

    Show answer guidance

    Hardware is the physical equipment; software is the instructions and associated data.

  12. What is a stored-program architecture?

    Show answer guidance

    An architecture in which instructions are represented in memory alongside data.

  13. What is Unicode?

    Show answer guidance

    A standard assigning code points to characters across many writing systems.

  14. Why are ethics important in computing?

    Show answer guidance

    Computing decisions affect privacy, fairness, safety, access, security and public trust.

  15. What is DNS used for?

    Show answer guidance

    It resolves domain names to network information such as IP addresses.
