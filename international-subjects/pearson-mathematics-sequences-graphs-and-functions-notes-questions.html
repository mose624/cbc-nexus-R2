Chapter 4: Sequences, graphs and functions

A sequence is an ordered list following a rule. For an arithmetic sequence, the difference between consecutive terms is constant. The nth term of an arithmetic sequence is a + (n − 1)d, where a is the first term and d is the common difference.

Core explanation

Coordinates locate points using an x-coordinate and y-coordinate. A straight-line graph has equation y = mx + c, where m is gradient and c is the y-intercept. Gradient = change in y ÷ change in x. Parallel lines have equal gradients; perpendicular gradients multiply to −1 (when both are defined).

Worked example / application

Worked example: 5, 8, 11, 14,... has common difference 3. Its nth term is 3n + 2. For y = 2x − 4, the gradient is 2 and the y-intercept is −4.

Further textbook notes: sequences and functions

An arithmetic sequence has a constant first difference; its nth term is a+(n−1)d. A geometric sequence has a constant multiplier. A function maps each allowed input to exactly one output; the domain is the set of allowed inputs and the range is the set of outputs. For a straight-line graph y=mx+c, m is the gradient and c is the vertical intercept. Parallel lines have equal gradients.

Three additional worked examples — different approaches

Study each method, compare the reasoning and use the final check to verify your answer. These are original teaching examples designed to build flexible problem-solving skills.

Worked example 1: Method 1 — term-to-term pattern

Question: Find the nth term of 6, 10, 14, 18, …

Step-by-step solution: The common difference is 4, so begin with 4n. When n = 1, 4n = 4; add 2 to obtain the first term 6. The nth term is 4n + 2.

Check / exam insight: Check n = 3: 4(3) + 2 = 14.

Worked example 2: Method 2 — gradient from two points

Question: Find the gradient of the line through (−2, 3) and (4, 15).

Step-by-step solution: Gradient m = change in y ÷ change in x = (15 − 3)/(4 − (−2)) = 12/6 = 2.

Check / exam insight: A positive gradient means the line rises from left to right.

Worked example 3: Method 3 — function machine

Question: Given f(x) = 3x − 5, find f(4) and solve f(x) = 10.

Step-by-step solution: For f(4), substitute 4: 3(4) − 5 = 7. For f(x) = 10, solve 3x − 5 = 10, so 3x = 15 and x = 5.

Check / exam insight: Substitution confirms f(5) = 10.

Exam-style question (3 marks)

Show model answer and mark allocation

Common difference=4 (1); nth term begins 4n (1); first term requires −? 4(1)+3=7, so 4n+3 (1).

Examiner’s explanation: Check the rule against at least the first two terms.

Exam technique: Show each formula, substitution, calculation and unit. For “explain” questions, connect the scientific idea to the outcome; for “describe” questions, give the relevant sequence or features.
