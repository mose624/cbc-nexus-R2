# CBC Nexus — Grade 7 Creative Arts and Sports

Added a 30-question, 30-mark multiple-choice practice assessment for Grade 7 Creative Arts and Sports.

## Coverage
- Visual arts and design
- Music, dance and rhythm
- Drama and performance
- Sports tactics and safety
- Fitness, hydration and sportsmanship
- Integrated creative arts, event planning, inclusion and feedback

## Answer key
The correct option positions, in question order, are:

C, A, D, B, C, D, A, B, C, A, D, B, C, A, D, B, C, A, D, B, C, A, D, B, C, A, D, B, C, A.

The key and feedback explanations are derived from the supplied practice questions. This paper is original practice material, not an official KNEC examination.

## Timing
The site-wide assessment timer remains at two minutes per question (60 minutes for 30 questions). The source paper states 45 minutes; the website setting remains unchanged to preserve the existing learner workflow.

## Deployment
The files are packaged for review/deployment. Creating this package does not publish the site to cbenexus.co.ke. Online persistent results and cross-device one-attempt enforcement require the existing Supabase deployment/configuration to be completed.
