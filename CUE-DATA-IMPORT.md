# CUE official data import

CBE Nexus uses the Commission for University Education as the source of truth for university status and accredited academic programmes.

Current CUE publications: Approved Universities — 15 September 2026; Accredited Academic Programmes — 31 July 2026; Classification of Universities Academic Programmes — Code Book.

Do not populate this database with guessed or generic course names. The website only labels records as CUE data after an official CUE export has been imported.
