Quick setup notes

The online AI written marking, one-attempt enforcement and timed submissions require a Supabase project and the included Edge Function. Review these repository files for full instructions and configuration examples:

  • README_AI_WRITTEN_MARKING_AND_TIMING.md — AI marking, timer and deployment overview (recommended start).
  • supabase-config.js — public Supabase URL/publishable-key placeholders (do NOT add secret keys here).
  • cbenexus-all-grades/supabase/schema.sql — database schema (run in Supabase SQL editor).
  • cbenexus-all-grades/supabase/functions/ — Edge Function source (cbc-nexus-results).
  • index.html — main site with learner gate and Teacher Dashboard.

Important: never paste OpenAI API keys or Supabase service-role/secret keys into browser files or public repos. Follow the README_AI_WRITTEN_MARKING_AND_TIMING.md steps to configure server-side secrets and deploy the Edge Function.
