# Grade 7 Mathematics added to CBC Nexus

- Added the supplied Grade 7 Mathematics practice examination as a dedicated 30-question multiple-choice bank.
- Covers numbers and operations, algebra and patterns, geometry and measurement, ratio/proportion/rates, data handling/probability, and financial mathematics.
- Suggested answer key and a calculation explanation are stored with each question for feedback.
- Added Grade 7 Mathematics to the quick-access assessment hub and preserved the existing Grade 8–10 banks and site features.
- The source paper says 45 minutes. The site's established timing rule remains 2 minutes per question, so this assessment is allocated 60 minutes.
- **Question 30 correction:** The supplied options omitted the calculated answer. A 25 m by 15 m rectangle has perimeter 80 m, and 80 × KSh 120 = KSh 9,600; option D was corrected from KSh 9,000 to KSh 9,600.
- This is practice material, not an official KNEC examination. The suggested answer key should be reviewed by a teacher before formal use.
