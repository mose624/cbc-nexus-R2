Undergraduate pathway

About this Computer Science study guide

Computer Science studies the foundations, design, implementation and analysis of computational systems. It combines mathematical reasoning with practical programming and engineering. Students learn how information is represented, how algorithms solve problems, how software is designed and tested, how computers execute instructions, how networks exchange data, and how intelligent systems learn from examples.

This guide is organised into four illustrative academic years and sixteen major subject areas. It is intended as a coherent learning pathway rather than a claim that every university uses an identical syllabus. Course names, credit values, prerequisites, programming languages and semester order vary among institutions and national accreditation frameworks. Students should compare this guide with the approved programme handbook of their university.

Study standard: Each chapter is planned as a substantial university-level learning resource with carefully explained theory, worked examples, labelled diagrams, practical activities, revision summaries and assessment questions. Programming examples should be run, tested and modified rather than memorised.

Programme learning outcomes

  • Translate real-world problems into precise computational specifications and algorithms.
  • Write, test, debug and document programs using appropriate programming paradigms.
  • Apply discrete mathematics, logic, probability and linear algebra to computing problems.
  • Explain computer architecture, memory hierarchy, operating systems and network protocols.
  • Choose data structures and algorithms using time and space complexity analysis.
  • Design relational databases and reason about transactions, integrity and query performance.
  • Apply software engineering practices including requirements analysis, version control, testing and maintenance.
  • Evaluate AI and machine-learning methods, their limitations, bias, privacy and societal impact.
  • Assess security risks and design layered protections for systems and information.
  • Plan and communicate a reproducible computing project using ethical research methods.
